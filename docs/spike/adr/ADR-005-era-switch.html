ADR-005 — 시대 전환은 과거 배경 SOG 교체가 필수, 모바일 기본은 해제 후 로드

  • 상태: 채택 (2026-09-30)

맥락

init 요구는 "현재 Splat ↔ 과거 배경 Splat + GLB". 1차 설계는 GLB 토글만으로 완료 처리했고 두 번째 Splat을 미뤘다(R01). GLB만 얹으면 기존 구조물과 복원물이 겹쳐 보이고, 두 Splat의 로딩·해제·전환 비용을 놓친다.

결정

  • 자산: current.sog, historical-base.sog(현재 master에서 시험 구조물 영역만 오프라인 편집으로 제거한 파생본), historical-object.glb. 실제 역사 재현이라고 주장하지 않는다. 편집 후 구멍·잔상은 관찰 결과에 기록.
  • 상태 전이 하나로 처리: 버튼 → 입력·중복 클릭 차단 + 상태 표시 → (모바일 기본) 현재 시대 자산 해제 → 대상 시대 자산 로드 → 레이어 변경 → 카메라·이동 복귀. 새 시대에 없는 Hotspot 패널은 닫는다.
  • 실패 시 오류·재시도 표시, 이전 시대는 필요하면 다시 로드. 복구를 위해 두 장면이 상주한다고 가정하지 않는다.
  • enabled=false/visible=false는 표시 제어이지 해제가 아니다. 20회 반복 후 자산 수·해제 로그로 누적 여부를 확인한다.
  • 기본은 불투명 GLB + 명시적 교체로 검증. GLB 0.3초 페이드는 양쪽 같은 조건의 별도 시험(F8).
  • 두 장면 상주(빠른 재전환)는 기본 측정과 분리한 최적화 실험.

결과

해제 후 로드 정책의 대기 시간도 결과다. 최초 전환(다운로드 포함)과 재전환을 분리해 측정한다.
