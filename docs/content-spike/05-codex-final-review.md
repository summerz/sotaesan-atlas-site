## FINAL 반영 조건 — 수정 문안

1. **04 §2 자산 고정 범위.** 원본 해시만 적으면 분할 장면의 식별이 불충분하다. 다음으로 보완한다. “원본 해시는 출처 식별용이다. 실행에 사용하는 `sunnyvale-era`의 분할·LOD·충돌 및 추가 자산 해시와 빌드를 함께 고정한다.” (03 §1·§3·§4 질문 2)

2. **04 §4 예산 조건.** 숫자는 맞지만 전제와 추가비 승인 조건이 빠졌다. 총계 뒤에 추가한다. “이용 조건이 확인된 간단한 음원·인물 자산, 자료·검수자 확보를 전제로 하며 새 고품질 모델 제작은 제외한다. 축별 비용은 구현·단독 시험, 공통비는 횡단 작업으로 중복 계산하지 않는다. 새 장면 +3.5–7인일은 조사 0.5–1과 준비 3–6이며 복잡한 하늘 제거 비용은 제외한다. 상한을 승인받지 못하면 해당 축을 보류한다. 촬영 제약 전달은 이번 범위지만 후속 촬영 체크리스트 협의 0.5–1인일은 별도다.” (03 §4 질문 3·4)

3. **04 §3 복구 판정.** 실패 목록은 유지하고 연출 기준 뒤에 추가한다. “취소·복구 완료 후 수동 입력·카메라·음성·활성 구역·시대가 사전 정의 상태인지 확인한다. 구역 준비 대기의 타임아웃과 자막·수동 탐색 대체 경로를 정의한다. 요청 시작을 준비 완료로 세지 않으며 사전 로딩 시간도 사용자 대기 비용에 포함한다.” (03 §2.4·§4 질문 5)

4. **04 §3 시각 합격선.** ‘이전 하늘 잔존 0건’은 03의 ‘뚜렷한 잔존’보다 엄격해졌다. 하늘 기준을 보완한다. “고정 8시점과 경로에서 비교한다. 보존할 지붕·줄기 소실, 새 구멍, 이전 하늘의 뚜렷한 잔존은 0건이다. 기존 결함과 새 결함을 구분하고 미세 번짐은 사전 승인 예시·지정 판단자로 판정한다.” 왕복 행에는 “전 구간 발 기준점 오차 5cm 이내”를 추가한다. (03 §4 질문 5)

5. **04 §4·§5 측정 조건.** 다음을 추가한다. “기기별 동일 경로·빌드·자산·viewport·캐시 조건으로 비교하며 켜고 끈 직후 heap을 cold 실행과 비교하지 않는다. 증가 5ms는 전체 프레임 간격 p95의 증가량이다. 축 보류 시 통과한 축의 결합 구성으로 줄인다.” (03 §4 질문 2·5)

6. **04 §1·§7 해석 한계.** §1의 후속 평가 설명 뒤에 “과제·비교 조건·표본을 다시 설계하며 01의 8명을 확정 기준으로 승계하지 않는다”를 추가한다. §7 첫 열 제목은 “재사용 후보(이전 시험으로 확인)”로 바꾸고 “공통 구현비와 장소별 재저작 인시를 분리하며, 실패·미시험 축은 이전 성공으로 세지 않는다”를 덧붙인다. (03 §2.1·§4 질문 4·5)

이 보완을 반영하면 기존 합의와 일치한다. 추가 논쟁이나 새 기능 조건은 없다.
