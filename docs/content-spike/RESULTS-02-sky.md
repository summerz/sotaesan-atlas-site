# 콘텐츠 스파이크 2차 결과: 하늘 고정 8시점 비교

- 작성일: 2026-10-16
- 대상 계획: [FINAL.md](FINAL.md) §3 하늘 행
- 환경: PlayCanvas 2.22.6, 장면 `sunnyvale-content`, Playwright headed Chromium, `ANGLE Metal Renderer: Apple M4 Pro`(하드웨어 GPU), 창 1200×863, DPR 2
- 비교 조건: 같은 시점에서 `?axes=none`(원본 스트립)과 `?axes=sky`(반경 100m 밖 제거 스트립 + 돔)
- 시점 고정 방법: 시험 브라우저에서 `sunnyvale-content.json` 응답의 `spawn` 위치·회전만 바꿨다. 소스 파일은 바꾸지 않았다. 요청 가로채기를 썼으므로 이 실행으로 로딩 비용을 판정하지 않는다.
- 근거: [evidence/sky8/](evidence/sky8/)의 비교 이미지. 왼쪽이 원본, 오른쪽이 하늘 교체

## 1. 이번 회차 수정

1차 결과의 "지평선 아래로 돔 색이 비친다" 문제를 돔 쪽에서 고쳤다. 돔의 눈높이 아래를 어두운 녹회색(0.27, 0.30, 0.25)으로 칠했다. 제거된 먼 스플랫은 반경 100m 밖 약 3,600개(상세 90만 개 중)였고, 대부분 수평선 위 0–15° 사이의 회색 배경이었다. 자산을 다시 만들지 않았다.

## 2. 시점과 결과

시점은 `[pitch, yaw, roll]`이고 단위는 도다. yaw 0은 −Z 방향이다.

| 시점 | 위치 | 회전 | 대상 | 결과 |
|---|---|---|---|---|
| v1 열린 하늘 | [0, 0.17, 0] | [25, 0, 0] | 광장 위 하늘, 왼쪽 2층 현관 건물 | **결함**. 현관 건물이 반투명해져 형태가 흐려짐 |
| v2 가지 | [0, 0.17, 0] | [20, 25, 0] | 앙상한 나무 가지, 현관 건물 | **결함**. 가지는 보존. 현관 건물이 반투명, 앞쪽 floater 다수 |
| v3 지붕 | [0, 0.17, 0] | [8, 15, 0] | 흰 지붕 집, 현관 건물 | **결함**. 흰 지붕 보존. 현관 건물 반투명 |
| v4 야자 | [3.1, 0.17, −1.4] | [30, −15, 0] | 야자 줄기·잎 | 줄기·잎 보존. floater 드러남 |
| v5 구역 경계 12m | [11, 0.17, −1.5] | [10, −90, 0] | 오른쪽 끝 관목 | 관목 보존. 원본도 촬영 범위 끝이라 잡음이 많음. floater 드러남 |
| v6 구역 경계 0m | [3.1, 0.17, −1.4] | [10, 90, 0] | 왼쪽 촬영 범위 밖 | 원본·교체 모두 판별 불가. 원본이 이미 잡음뿐인 영역 |
| v7 오른쪽 낮은 시야 | [0, 0.17, 0] | [0, −45, 0] | 1차에서 틈이 보였던 곳 | 틈 해소. 눈높이 아래가 어두운 띠로 덮임 |
| v8 뒤쪽 | [0, 0.17, 0] | [15, 180, 0] | 지붕 집, 가로등, 큰 나무 | 지붕·가로등·가지 보존. floater 드러남 |

계획의 판정 항목별 정리다.

- **보존할 지붕·줄기 소실**: 3건(v1–v3, 같은 현관 건물). 스플랫이 지워진 것이 아니다. 반투명한 건물 스플랫 뒤를 막던 어두운 원거리 스플랫이 사라져 밝은 돔이 비친다. 원인은 기존 재구성 결함이지만 보이는 결과는 건물 소실에 가깝다.
- **새 구멍**: 0건. 1차의 지평선 틈은 v7에서 해소됐다.
- **이전 하늘의 뚜렷한 잔존**: 0건. 원본의 짙은 파란 얼룩은 8시점 모두에서 사라졌다.
- **기존 결함이 드러남**: 흩날리는 잎 floater가 8시점 모두에서 밝은 하늘 앞에 보인다.

## 3. 판정

현재 방식(반경 제거 + 단색 그라데이션 돔)으로는 하늘 축의 통과 기준을 충족하지 못한다. 막는 항목은 현관 건물의 반투명 노출이다. 미세 번짐이 아니라서 승인 예시 없이도 결함으로 본다. 최종 판정은 지정 판단자가 비교 이미지로 확인한다.

이 결과는 대역 장면의 성질에 크게 좌우된다. Sunnyvale 장면은 하늘과 먼 배경이 거의 재구성되지 않아 짙은 스플랫이 배경을 대신하고 있었다. 실제 성지 촬영에서 하늘 영역을 따로 분리하는 비용은 이 결과로 추정할 수 없다.

## 4. 다음 선택지

1. 하늘 축을 "실패 보고"로 닫는다. 계획 §3은 상한 도달 시 실패 보고도 유효 산출물로 인정한다. 추가 비용이 없다.
2. 돔을 어둡게 해 원본 분위기에 가깝게 맞춘다. 반투명 노출은 줄지만 하늘 교체의 의미가 약해진다. 0.1인일 미만이다.
3. 현관 건물 주변에만 원거리 스플랫을 남기는 영역 예외를 둔다. 장면 전용 수작업이라 실제 성지로 옮길 수 없다. 0.5인일 정도다.
4. floater 제거 필터(`splat-transform -F`)를 먼저 시험한다. 잎과 가지를 함께 지울 위험이 있다. 0.5인일 정도다.

추천은 1이다. 2–4는 이 대역 장면의 결함을 손보는 일이고, 실제 성지로 옮길 수 있는 지식이 적다.
