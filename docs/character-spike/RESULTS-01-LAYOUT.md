# 1회차 보완: 아바타 구도와 단일 안내 패널

- 작성일: 2026-11-07
- 대상: PlayCanvas `?scene=content&character=1`, 통로 시험 `&cameraLab=1`
- 앞선 결과: [1회차](RESULTS-01.md). 이번 변경 후 결과는 별도 보존하며 이전 측정에 합치지 않는다.

## 반영한 요청

아바타를 화면 하단 중앙으로 내리고, 주변 공간이 위쪽에 더 보이도록 시선 목표를 몸 중심보다 높였다. 카메라 거리 3.8m는 유지했다. 기본 궤도 pitch는 -15°에서 -28°로 바꾸고, 입력 범위는 -55°~+10°에서 **-50°~-20°**로 제한했다. 이 값은 아바타 주위 카메라 위치의 궤도 각도이며, 구도를 위한 시선 오프셋이 있어 실제 광축 각도와 같지 않다. 가까운 장애물 앞에서는 오프셋도 거리에 맞춰 줄인다.

이번 캐릭터 모드의 안내·상태·시작점·음소거·통로 링크를 한 패널로 모았다. PC와 모바일 모두 **닫힌 상태로 시작**하고, 기존 패널의 저장된 펼침 설정을 따르지 않는다. 닫으면 ‘안내·조작’ 버튼 하나만 남는다. 열면 닫기 버튼은 상단에 유지하고 내용만 내부 스크롤한다. Esc는 패널 내부 포커스에서 닫고 토글 버튼으로 포커스를 돌린다. 초기 로딩 오류는 재시도 버튼을 볼 수 있도록 패널을 연다.

패널에는 임시 아바타·대역 장면 안내, 현재 카메라 상태, 키보드·마우스·터치 조작, 야외/통로 이동, 시작점과 음소거만 표시한다. 엔진·장면 선택, 시대 전환, 벤치마크·충돌 진단 등은 이번 시험 화면에서 제외했다. 기존 1인칭 URL의 패널은 유지한다.
