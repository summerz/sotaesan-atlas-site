# 2회차: NPC 접근 인사·사용자 답례

- 날짜: 2026-11-07
- 대상: PlayCanvas + Sunnyvale, `?scene=content&character=1`
- 판단: 이동 보완은 종료하고, NPC 인사 흐름까지 진행했다. 표현은 임시 수준이며 안내문 전달은 다음 회차다.

## 적용

시작점 앞 오른쪽 `(1.5, 0.1544, −3)`에 고정 NPC를 두었다. 기존 Quaternius Casual Character(CC0)를 재사용하며 [동일 자산·라이선스](ASSET-LICENSE.md)를 적용한다. **교무님 역할을 시험하는 일상복 임시 모델**로, 교무님 복장이 완성된 것은 아니다.

| 행동 | 현재 동작 |
|---|---|
| 접근 | 2.6단위 이내 진입 시 NPC가 사용자를 향해 손을 모으면서 허리를 약 15도 숙임. 허리를 완전히 편 뒤 손을 내림. 약 2.4초 |
| 답례 | 가까이서 멈춘 뒤 G 또는 하단 합장 버튼. 사용자도 NPC를 향해 같은 자세를 취함 |
| 이동 | 사용자 답례 중 움직이면 취소하고 이동 애니메이션으로 복귀 |
| 중복 | G를 누른 채로 반복 실행하지 않음. 동작 중 재입력 차단 |
| 재접근 | 3.5단위 밖으로 벗어난 뒤 재진입해야 NPC 재인사. 직전 시작으로부터 6초 간격 |
| 버튼 | 근처에 있을 때만 표시. 이동 중·답례 중 비활성화. 안내 패널은 기존 단일 접기 버튼 유지 |
| 복귀 | R로 시작점·인사 상태 초기화. 좁은 카메라 시험 모드에는 NPC를 추가하지 않음 |

NPC 개인 공간은 정적 캡슐로 막는다. 손·팔 자세는 기존 뼈대에 절차적 보조를 적용하고 렌더 후 원래 자세로 복구한다. 전용 합장 애니메이션이나 손바닥 접촉·손가락 자세의 완성도를 보장하지 않는다. NPC는 실제 종교 인물의 재현이 아니다.

구현: [인사 상태·자세](../../apps/spike-playcanvas/src/character-greeting.ts), [캐릭터 연결](../../apps/spike-playcanvas/src/character.ts). 안내문·대화·다중 사용자 연결은 미구현이다.

## 확인

별도 headed Playwright CLI `steps`, 시험 탭 1개, Apple M4 Pro / ANGLE Metal. 최종 환경은 1200×919, DPR 1이며 모바일 크기는 390×844다. 개발 서버 기능 시험이고 실기기·성능 검증은 아니다.

| 시험 | 결과 |
|---|---|
| 접근 자동 인사 | 범위 안에서 NPC 인사 횟수 1회 증가 |
| G 답례 | 사용자 인사 상태 진입, 양쪽 자세 화면 확인 |
| G 누른 채 유지 | 인사 횟수 추가 증가 없음 |
| 근처 정지 대기 | 6.5초 대기 후 NPC 반복 인사 없음, 사용자 답례 종료 |
| 이동 취소 | S 입력 후 사용자 인사 남은 시간 0 |
| 범위 밖 이탈·재접근 | 이탈 상태 확인 후 NPC 인사 횟수 1회 증가 |
| 모바일 크기 버튼 | DOM 버튼 클릭으로 답례, 화면 가로 넘침 없음. 실제 손가락 입력 시험은 아님 |
| 자동 시험 | 신규 인사 상태 회귀 2개 포함 총 104개 통과. 타입·빌드·자산 검사 통과 |

처음 브라우저 시험에서 추가 사용자 인사가 발생해 `noRepeat`가 실패했다. 원인은 확정하지 않았다. G 누름 상태를 명시적으로 추적하고 keyup/blur에 해제하는 방어를 추가한 뒤 동일 시퀀스의 9개 판정이 모두 통과했다. 변경 전 실패 원본을 보존했으며 최종 결과에 섞지 않는다. 콘솔에는 기존 favicon 404만 있었다. 빌드 식별자는 `local-c5b967dd2a7e-bdb58c9a474c`다.

## 합장 자세 보완 (2026-11-07 사용자 피드백)

사용자가 합장 동작의 어색함을 지적했다. 이전 자세는 손목 위치만 모으고 손의 한 축만 위로 돌렸으며, 대기 애니메이션의 손가락 굽힘과 손목 비틀림을 남겼다. NPC와 방문자 모두 같은 원인이었다.

- 모델의 inverse bind pose에서 손가락 기본 회전을 복원하고 손가락을 펴서 나란히 정렬했다. 손가락 뿌리의 간격은 유지한다.
- 손목의 전체 회전을 지정해 손바닥이 마주 보도록 하고, 가슴 앞에서 양손의 간격·높이와 팔꿈치 방향을 조정했다.
- 손 위치만 보간하던 방식에서 팔·손목·손가락 전체의 회전을 함께 보간하도록 바꿨다. 렌더 후 원래 애니메이션 자세로 복구한다.

기존 headed `steps` 탭에서 양쪽 아바타의 동작과 NPC 정면·측면 확대 화면을 확인했다. 확대 촬영에만 앱 시간을 잠시 멈추고 카메라를 바꿨으며 `finally`에서 복원했다. 실제 탐색 카메라 설정은 바꾸지 않았다. 기존 브라우저 인사 흐름 9개 판정(접근·답례·누름 유지·반복 방지·이동 취소·이탈·재접근·모바일 크기 버튼·넘침)이 모두 통과했고, PlayCanvas 시험 23개·타입 검사·빌드도 통과했다. 모바일 크기 확인은 데스크톱 에뮬레이션이다. 교무님 복장은 여전히 임시 모델이며, 전용 합장 애니메이션을 추가한 것은 아니다.

## 허리 인사 순서 보완 (2026-11-07 사용자 피드백)

사용자가 손을 모으면서 허리를 약 15도 숙이고, 허리를 완전히 편 다음 손을 원래대로 돌리는 순서를 지정했다. NPC와 방문자 모두 고개만 기울이던 보조 동작을 제거하고 허리 관절에서 상체를 숙이도록 바꿨다. 모은 손은 가슴과 함께 움직이며 하체는 이 보조 회전의 영향을 받지 않는다.

| 인사 시작 후 | 동작 |
|---|---|
| 0–0.5초 | 손을 모으면서 허리 0→15도 |
| 0.5–1.1초 | 합장·15도 숙임 유지 |
| 1.1–1.7초 | 손을 모은 채 허리 15→0도 |
| 1.7–1.9초 | 바로 선 상태에서 합장 유지 |
| 1.9–2.4초 | 바로 선 채 손을 원래대로 |

이동·포커스 이탈로 답례가 취소될 때도 허리를 먼저 편 뒤 손을 내리도록 했다. 전체 인사 시간·접근 범위·재인사 간격은 유지한다.

기존 headed Playwright `steps` 단일 탭에서 NPC와 방문자의 렌더 직전 관절과 렌더 후 원래 관절을 같은 프레임에 비교했다. 두 인물 모두 최대 추가 숙임이 약 15도였고, 손을 내리는 표본에서는 허리 추가 회전이 0이었다. 허리를 펴는 동안 손 모으기 가중치는 1을 유지했으며, 이 자세 보조로 인한 골반·발 좌표 변화는 없었다. 정면·측면 화면도 확인했다. 확대 촬영용 시간 정지·카메라는 `finally`에서 복원했다. 이 관절 비교는 동작 확인이며 성능 측정은 아니다.

순서 검사 1개를 추가해 PlayCanvas 시험 24개·타입 검사·빌드가 통과했다. 기존 브라우저 입력 흐름 9개 판정도 모두 통과했다. 모바일 크기 버튼 검사는 데스크톱에서 수행했다. 브라우저는 다시 시작점에 두었다.
