대종사 십상과 관련 성지를 웹 가상 공간으로 구현하기 위한 사전 기술 시험입니다. 특정 플랫폼에 되도록 묶이지 않도록 공통 자산과 장면 데이터를 사용했습니다. 여기서는 실제 성지 대신 웹에서 내려받은 Knock Community Hall과 Sunnyvale Museum 샘플을 실행합니다. 촬영·사진에서 스플랫 생성·역사 복원은 이번 시험에 포함하지 않았습니다. 프로젝트 배경과 샘플 출처 보기

조작 방법

  • 화면을 클릭하고 WASD로 이동합니다. 마우스로 시선을 돌리고 Esc로 마우스를 해제합니다.
  • ‘과거 보기 / 현재 보기’로 시대를 전환하고, 장소 이름을 눌러 설명을 확인합니다.
  • ‘충돌 면 보기’로 바닥과 벽을 확인합니다. ‘시작점으로’ 또는 R로 돌아갑니다.
  • ‘위치 JSON 저장’으로 현재 상태를, ‘비교 경로 재생’ 후 ‘결과 JSON 저장’으로 측정 결과를 내려받을 수 있습니다.

모바일에서는 화면의 이동·시선 터치 영역을 사용합니다. 대형 원본이 열리지 않으면 기본 공간 또는 구역 로딩 장면부터 확인해 주세요. 엔진을 바꿔 비교할 때는 기존 테스트 탭을 닫고 하나씩 실행하면 됩니다.
